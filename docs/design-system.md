# Design system

## Design read

This is a technical control room for a hackathon product. It should feel like a premium mission interface, not a crypto wallet and not a chat demo.

## Direction

- Dark locked theme.
- Emerald accent.
- Geist typography.
- Rounded double-bezel containers.
- Soft blurred shadows only.
- Motion communicates sequence, orbit and state readiness.
- Future functions are visible as Soon, not hidden.

## UI rules

- No hard offset shadows.
- No generic AI-purple gradient treatment.
- No real trading language that implies execution.
- Disabled providers must have no buy action.
- Secrets can only show as boolean readiness.
